# LipaFlow

A payments and invoicing platform for Kenyan small businesses.

## Planned features
- [ ] Customer management
- [ ] Invoice creation with VAT
- [ ] M-Pesa payments
- [ ] SMS receipts
- [ ] KRA eTIMS compliance
- [ ] Reports dashboard

## Tech stack
- React (Vite)
- Node.js, Express, MongoDB (coming)

## Run locally
npm install
npm run dev
